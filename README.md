# Task Manager API

واجهة REST API لإدارة المهام، مبنية باستخدام Node.js وExpress.

## التشغيل

1. ثبّت الاعتماديات باستخدام `npm install`.
2. انسخ `.env.example` إلى `.env` وعدّل القيم عند الحاجة.
3. شغّل وضع التطوير باستخدام `npm run dev`، أو التشغيل العادي باستخدام `npm start`.

الخادم يعمل افتراضيًا على المنفذ `5000`. للتحقق من حالته، أرسل طلب GET إلى `/health`.

## بنية المشروع

- `controllers/`: معالجة طلبات API.
- `models/`: نماذج البيانات.
- `routes/`: تعريف المسارات.
- `middleware/`: برمجيات وسيطة للطلبات.
- `config/`: إعدادات التطبيق.
- `server.js`: نقطة تشغيل الخادم.
